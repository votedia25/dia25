# Sufrágio app

App web estático, independente e apartidário: resultado do 2º turno de 2026 por estado (mapa 3D) e a história do voto no Brasil, com fonte em cada afirmação.

Publicação: GitHub Pages, branch `main`, pasta raiz. Código-fonte em `sufragio/` na máquina do autor; este repositório recebe o resultado do `build.py`.

A versão anterior (Dia 25, material de opinião de apoiador) está na tag `dia25-final`.
